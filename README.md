# 펨코 아이디 가리기

에펨코리아(fmkorea.com)에서 글쓴이/댓글 작성자의 닉네임을 **블러 처리하거나 완전히 숨겨주는** 스크립트입니다.
친목 방지 목적으로 사용하세요.

## 설치 방법

### 1단계. Tampermonkey 설치

먼저 브라우저에 "Tampermonkey"라는 확장 프로그램을 설치해야 합니다. (스크립트를 실행시켜주는 필수 프로그램)

- 크롬(Chrome) 사용자: [Tampermonkey 설치 링크](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- 엣지(Edge) 사용자: [Tampermonkey 설치 링크](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)

링크 접속 후 **"Chrome에 추가"** (또는 "설치") 버튼을 누르면 끝입니다.

### 2단계. 스크립트 설치

아래 링크를 클릭하세요.

**[👉 여기를 클릭해서 설치하기](https://raw.githubusercontent.com/yololo333/fm-id-hider/main/fmkorea-id-hider.user.js)**

링크를 누르면 설치 확인 화면이 새 탭에 뜹니다. 화면에서 **"설치(Install)"** 버튼을 누르면 설치가 완료됩니다.

> 만약 화면에 아무것도 안 뜨거나 이상한 텍스트만 나온다면, 1단계의 Tampermonkey 설치가 안 된 것이니 다시 확인해주세요.

### 3단계. 확인

설치가 끝나면 에펨코리아(fmkorea.com)에 접속해보세요. 자동으로 닉네임이 블러 처리되어 보입니다.

화면 오른쪽 아래에 빨간 동그란 버튼(🙈)이 떠 있는데, 이걸 누르면 설정 창이 나옵니다.

## 사용법

오른쪽 아래 🙈 버튼을 누르면 이런 설정을 할 수 있어요.

| 기능 | 설명 |
|---|---|
| 사용 켜기/끄기 | 스크립트 전체를 껐다 켤 수 있어요 |
| 블러 / 숨기기 | "블러"는 흐리게 처리(마우스 올리면 잠깐 보임), "숨기기"는 아예 안 보이게 처리 |
| 🎯 놓친 아이디 직접 선택하기 | 혹시 안 가려진 닉네임이 있으면, 이 버튼을 누른 뒤 그 닉네임을 클릭하세요. 자동으로 가려집니다 |

## 안 가려지는 닉네임이 있어요

버튼을 눌러도 해결 안 되면, 어떤 화면(게시글 목록/본문/댓글/답글 등)에서 안 보이는지 캡처해서 알려주시면 수정해드릴게요.

## 자주 묻는 질문

**Q. 이 스크립트, 내 정보를 어디로 보내나요?**
A. 아니요. 순수하게 화면에 보이는 닉네임을 흐리게/숨기게만 하는 스크립트이고, 어떤 정보도 외부로 전송하지 않습니다.

**Q. 나중에 지우고 싶어요.**
A. 브라우저에서 Tampermonkey 아이콘 클릭 → 스크립트 목록에서 "펨코 아이디 가리기" 옆의 휴지통(삭제) 아이콘을 누르면 됩니다.

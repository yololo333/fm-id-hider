# 에펨코리아 아이디 가리기

에펨코리아(fmkorea.com)에서 글쓴이/댓글 작성자의 닉네임을 **블러 처리하거나 완전히 숨겨주는** 크롬 확장 프로그램입니다.
친목 방지 목적으로 사용하세요.

## 설치 방법 (크롬 / 웨일 / 엣지 공통)

### 1단계. 파일 다운로드

이 페이지 위쪽에 있는 **`fmkorea-id-hider_1.zip`** 파일을 클릭한 다음, 우측 상단의 **다운로드(⬇) 아이콘**을 눌러서 저장하세요.
<img width="1131" height="491" alt="스크린샷 2026-08-21 203247" src="https://github.com/user-attachments/assets/64601e77-d9c3-4958-9378-a28bcd05a174" />

### 2단계. 압축 풀기

다운로드한 zip 파일을 우클릭 → **"압축 풀기"** (또는 "여기에 압축 풀기"). 폴더 하나가 생깁니다.

> 압축을 풀지 않고 zip 파일 그대로는 설치가 안 되니 꼭 풀어주세요.

### 3단계. 브라우저에 설치

1. 주소창에 아래 주소를 입력하고 이동하세요.
   - 크롬: `chrome://extensions`
   - 웨일: `whale://extensions`
   - 엣지: `edge://extensions`
2. 화면 오른쪽 위에 있는 **"개발자 모드"** 스위치를 켜주세요.(웨일은 하단)

3. 화면 왼쪽 위 (또는 상단)에 나타나는 **"압축해제된 확장 프로그램을 로드합니다"** 버튼을 클릭하세요.
4. 2단계에서 압축을 푼 폴더(`fmkorea-id-hider` 폴더)를 선택하세요.

## 사용법

브라우저 우측 상단 퍼즐(확장 프로그램) 아이콘을 누르고 "펨코 아이디 가리기"를 클릭하면 설정 창이 열립니다.

| 기능 | 설명 |
|---|---|
| 사용 켜기/끄기 | 확장 프로그램 전체를 껐다 켤 수 있어요 |
| 블러 / 숨기기 | "블러"는 흐리게 처리(마우스 올리면 잠깐 보임), "숨기기"는 아예 안 보이게 처리 |
| 🎯 놓친 아이디 직접 선택하기 | 혹시 안 가려진 닉네임이 있으면, 이 버튼을 누른 뒤 그 닉네임을 클릭하세요. 자동으로 가려집니다 |

## 안 가려지는 닉네임이 있어요

버튼을 눌러도 해결 안 되면, 어떤 화면(게시글 목록/본문/댓글/답글 등)에서 안 보이는지 캡처해서 알려주시면 수정해드릴게요.

## 자주 묻는 질문

**Q. 이 확장 프로그램, 내 정보를 어디로 보내나요?**
A. 아니요. 순수하게 화면에 보이는 닉네임을 흐리게/숨기게만 하는 프로그램이고, 어떤 정보도 외부로 전송하지 않습니다.

**Q. "개발자 모드"를 켜면 위험한가요?**
A. 개발자 모드는 크롬 웹스토어에 정식 등록되지 않은 확장 프로그램(지금 이 파일처럼)을 설치할 수 있게 해주는 설정일 뿐, 그 자체로 브라우저가 위험해지지는 않습니다. 다만 출처를 모르는 확장 프로그램은 설치하지 않는 게 좋습니다.

**Q. 나중에 지우고 싶어요.**
A. 확장 프로그램 관리 페이지(`chrome://extensions` 또는 `whale://extensions`)에서 "펨코 아이디 가리기" 찾아서 **"삭제"** 버튼을 누르면 됩니다.

**Q. 업데이트는 어떻게 하나요?**
A. 새 버전의 zip이 올라오면, 위 1~3단계를 다시 반복하면 됩니다(기존 확장 프로그램은 삭제 후 새로 설치, 또는 같은 폴더에 덮어쓰기 후 확장 프로그램 페이지에서 새로고침 아이콘 클릭).
